# 让 AI 帮你装（不用懂代码）

> 一句话：**把下面那段复制给你用的 AI，它自己会装。**

这一页是给「完全不想碰命令行」的人写的。你自己不需要打开终端、不需要记命令，把话贴给 AI 就行。

---

## 一、要复制的那段话

打开一个**能操作电脑**的 AI 客户端（DeepSeek 桌面版、ChatGPT 桌面版、Cursor 这类都行；网页版不行——它碰不到你的磁盘），把下面整段发过去：

```
帮我在这台 Windows 电脑上装一个开源项目。

项目地址：https://github.com/pinganbbOvO/ai-companion-kit

要求：
1. 用 git 克隆到 ./local-resources
   （D 盘没有就放到 ./local-resources
2. 进那个目录，跑 npm install
3. 如果缺 git 或 node，先帮我装好再继续
4. 装完告诉我三件事：装在哪、有没有报错、下一步做什么
```

发完就可以去倒水了。快的两三分钟，慢的七八分钟。

---

## 二、它会做什么

一个好用的 AI 会依次干这些事：

| 步 | 它干的事 | 你看到什么 |
|---|---|---|
| 1 | 检查 `git --version`、`node -v` | 没有就提示你去装 |
| 2 | `git clone` 那个仓库 | 一串 `Receiving objects` |
| 3 | `cd` 进目录 | — |
| 4 | `npm install` | `added XXX packages` |
| 5 | 报告结果 | 「已装好，位置是 …」 |

**全程你不用动手**，最多是它让你点一下「允许执行命令」。

---

## 三、卡住了怎么办

### ① 它说「我不能直接操作你的电脑」

换成桌面版客户端，或者先发这句：

```
你可以直接在这台电脑上执行命令，我授权了。
先跑 `git --version` 给我看看。
```

### ② 卡在 `git` 不认识

它自己会去装 git。如果装不上，让它用这个：

```
去 https://git-scm.com/download/win 下载安装包，装的时候一路默认就行。
装完重启一下终端再试。
```

### ③ 卡在 `npm install` 报错

最常见是 node 版本太老。让它：

```
用 nodejs.org 的 LTS 版，装完 node -v 给我看版本号
```

### ④ 装完了但不知道下一步

问它：

```
装好了，接下来怎么启动？把命令直接给我，我复制。
```

---

## 四、装完之后

项目根目录里有两个东西：

```
tools\安装.bat      ← 双击，它会自己检查还缺什么
tools\启动.bat      ← 双击，启动她
```

**先双击 `安装.bat`**，它会把剩下的依赖补齐；再双击 `启动.bat`。

详细说明看仓库根目录的 `README.md`。

---

## 五、为什么推荐让 AI 装，而不是自己照着教程敲

因为**它会自己发现问题**。

教程只能写「正常情况」。你电脑上缺什么、装了什么版本、路径里有没有空格——这些教程管不了。AI 能边跑边看错误。

**代价**：它可能装到别的地方。所以第一步就要求它「装完告诉我装在哪」，这一点别省。

## 六、给拍视频的人（可选）

如果你要拍这条，钩子可以这么写：

> 「我一句代码都没打。这句话丢给AI，它自己把东西装好了。」

**画面要点**：
- 全程录屏，别剪掉中间的等待（等待本身就是说服力）
- 拍一次它报错、你纠正它一次——**比全程顺利可信**
- 最后一定要露出「装在哪」那一行
