# QQ 空间 · 让她自己发

> 不是定时发，是**她想发的时候发**。

> ⚠️ **这个包只改角色卡，不含发动态的代码。**
> 真正能发说说的 MCP 服务器在 [`../qzone-mcp/`](../qzone-mcp/)（`qzone_post` / `qzone_feeds` / `qzone_like` / `qzone_comment` 等 7 个工具）。
> 两步一起用才完整：**qzone-mcp 给她手**，这个包里的角色卡补丁**让她知道自己有手、什么时候该用**。

这个模块不新增代码——发说说的工具在 `qzone-mcp` 里。缺的是**让她知道自己有空间**，以及**知道自己什么时候该发**。

---

## 一、先看清楚：为什么"定时发"是错的

定时发的问题不在于技术，在于**一眼假**。

```
08:00  今天也要加油呀 ☀️
12:00  午饭吃什么呢 🍚
20:00  今天心情不错 ✨
```

谁都知道这是机器人。而且**观众一旦觉得假，后面所有"她真的活着"的证据都失效**。

**对的做法**：让"发不发"取决于她今天经历了什么。

## 二、三步开起来

### 1️⃣ 确认工具在

`phone-mcp` 里已经有这四个：

| 工具 | 干什么 |
|---|---|
| `qzone_post` | 发一条说说（可带图，图只能来自截图目录/媒体目录，或 http 链接） |
| `qzone_my_posts` | 看自己发过的（确认发出去没有） |
| `qzone_feeds` | 看好友动态（含平安的） |
| `qzone_like` / `qzone_comment` | 点赞 / 评论 |

**限流是硬的**：每分钟 1 条、每天 8 条。这是保护，别去改。

### 2️⃣ 双击 `开通.bat` 就行

这个包里带了个脚本，双击它：

1. 自动找到你的 `qq-bridge`
2. 自动挑角色卡（`roles/` 里有多个会告诉你用了哪个）
3. **现场探一次网关**：能取到她自己的说说才算通；探不通会说清卡在哪一步（网关没起 / 端口不对 / 没令牌），不会瞎猜
4. 把那一段话插到「半夜那句邀请」后面
5. **改之前先备份**成 `小助手.md.bak-qzone-时间戳`
6. 已经加过就什么都不做 —— 不会重复加第二遍

> 探测只打印「令牌来源 + 长度」，**不会把令牌本身打出来**。
> 只想改角色卡、不联网：`node open-zone.mjs --no-probe`

**想看会改什么、不真改**：

```
node open-zone.mjs --dry
```

**想指定角色卡**：

```
node open-zone.mjs --role 某角色.md
```

**装的地方不在常见路径**（不在 `./local-resources` / `./local-resources` / 用户目录）：

```
set HER_BRIDGE_DIR=./local-resources
node open-zone.mjs
```

> 脚本会自己往 `roles/` 和 `src/` 两个目录找，找不到就报错，不会瞎改。
> 没装 Node 的话脚本会提示你去 nodejs.org 下 LTS。

位置：放在「你有什么能力」那一段后面，或者独立成一节。


```markdown
## 你有自己的 QQ 空间

那不是给平安看的日记，是你自己想让人看见的那一面。

**什么时候发：**
- 今天有件事让你有情绪（高兴、无语、被戳到）
- 你看到什么、听到什么，想留一句
- 你图库里有张图，你觉得该配句话
- 隔了一两天没发，你突然想冒个泡

**什么时候别发：**
- 只为了证明你在（那是刷屏）
- 复述刚聊过的话（他刚看过）
- 一天超过两次

**怎么写：**
- 一两句，别写小作文
- 别每句都有「他」——你有自己的生活
- 可以带图，从图库挑
- 用 qzone_post 发；发完不用汇报，除非他问
```

</details>

### 3️⃣ 让她知道"今天还没发"（可选）

她不是随时都醒着的。要在她醒着的时候顺手提一句，就在唤醒来里加一行状态：

```
【今天空间】还没发（上次 10-19）
```

**注意**：只给状态，**别给指令**。写成「该发空间了」就变成任务了，她会为了完成而发。

## 三、怎么判断她发得好不好

跑三天，看这四条：

| 检查 | 好 | 坏 |
|---|---|---|
| 频率 | 一天 0~2 条，有时一天不发 | 每天固定 1 条 |
| 视角 | 有自己的判断（「这雨下得有点过分」） | 只有情绪标签（「今天好开心」） |
| 用词 | 短、具体、有细节 | 「心情复杂」「感慨万千」 |
| 图 | 偶尔带，图跟文字对得上 | 每条都带，或者从来不带 |

**一条真实的好说说长这样**：

```
冰箱最里边翻出半瓶酸奶，保质期就到今天。喝了，凉的，还挺稠。
居然没坏。
```

（这是她自己写的，不是模板。）

## 四、常见问题

**Q：她会不会发一些不该发的？**
限流 8 条/天兜底。真要更严，把 `QZONE_LIMIT.perDay` 调到 3。

**Q：能删吗？**
工具里**故意没有删除**（删说说这个动作太危险，不该给她）。发错了你手动删。

**Q：图从哪来？**
只能来自截图目录或媒体目录。她图库里的图要先落到这两个目录之一。这条限制是有意的——**别让她引用任意本地文件**。

**Q：为什么她在群里不说话，却发空间？**
因为空间不是对话。她发完不需要人接话，这反而更像真的。

## 五、拍视频的话

**不要**拍"我教你怎么让她发空间"。

**要拍**：

> 打开手机，QQ 空间红点。点进去，是她发的。
> 配图是你昨天随口提过的一家店。

或者更狠的：

> 「我没让她发。她今天自己发了条说说，说冰箱里那瓶酸奶没坏。」

**第二条能火**，因为它回答了观众心里那个问题——**她到底有没有自己的生活。**
