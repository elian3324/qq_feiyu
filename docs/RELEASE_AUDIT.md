# 开源整理与静态审计记录

日期：2026-10-25。检查范围为本次生成的整个开源目录，包括隐藏文件、源码、配置示例、文档、依赖声明与审计工具。

## 原项目保护

原目录始终只读；所有创建、清理与修改均发生在新开源目录。未停止、启动、连接或调整原机器人及其网关。整理期间对原项目 379 个源码、配置与相关静态文件建立 SHA-256 基线并复核，变化数为 0。该核对不要求原机器人自然产生的运行日志保持静止，也没有读取或改变其进程状态。

没有复制原项目的 `.git`；开源目录没有原历史、新提交、依赖安装副本或运行数据。静态检查使用的临时 Git 元数据仅在开源目录内创建并随后删除，没有形成发布历史。

## 功能保留与调整

保留当前机器人的 companion 主链路、OneBot 传输、DeepSeek/百炼兼容 API、群聊/私聊身份与目标判定、记忆后台整理、图像/GIF、本地与 QQ 收藏表情、TTS/ASR、视频/文件阅读、日记、主动私聊、空间行为决策与 Android MCP。

改为系统 Node/FFmpeg/ADB/Python，不依赖原本打包的绝对路径。手机与空间 MCP 可独立关闭；默认不会因缺少这些可选服务而强制连接。默认停止自主行为，所有密钥由部署者填写。

空间功能有明确的外部依赖变化：旧的受限协议改写实现未分发，空间适配改为配置的 HTTP 动作网关。发布、动态、点赞、评论、回复与自主决策逻辑仍在，但此仓库没有完整空间服务端；标准 NapCat 不保证支持完整空间动作。参见 [QZONE.md](QZONE.md)。不能将此限制描述为“完整空间能力已经独立部署验证”。

原本第三方桌面程序的安装、登录、原生补丁、进程管理、电源/关屏脚本，以及历史 DSH 桥接替代入口不在本版本部署路径中。新入口只启动当前代码目录的机器人；断线重连仍由 OneBot 客户端处理。

## 静态检查方法与结果

完整机器可读结果见 [static-checks.json](static-checks.json)，检查器为 `scripts/static_audit.py`：

- 遍历所有公开文件和隐藏文件，拒绝私人配置、历史、运行目录、二进制、媒体和准备阶段临时文件。
- 扫描常见 API Key、Token、JWT、私钥、明文凭据字段、URL 凭据、私人网络地址和本机绝对路径。
- 解析所有 JSON；对 Python 使用 `ast.parse`，对 JavaScript 使用 Node `--check`，不加载模块。
- 检查相对模块引用、配置指定的运行模块、安装模块对应的锁文件声明、工作区路径和依赖来源。
- 检查所有配置示例的凭据/设备字段为空、账号示例为虚拟值，以及默认部署账号/白名单为空。
- 使用 Git 自身的规则匹配检查 35 个应忽略或应分发的路径；包括 `.env`、账号配置、角色卡、聊天记录、数据库、媒体、依赖、日志与模板例外。
- 核对 npm 锁文件中的 97 条外部依赖安装记录；未保留受限 SDK 或未知许可声明。

最终检查结果为 PASS、0 个已知静态问题：87 个文件、17 个 JSON、47 个 JavaScript 文件、2 个 Python 文件，以及 35 项 Git 忽略规则验证。检查没有执行任何机器人模块、项目自检、业务测试、安装钩子或网络请求。

该结果不能证明不存在所有未知形式的秘密，也不代替依赖源码的全面安全审计。此版本没有业务运行验证，不应把静态通过等同于所有平台能力均已实测。
