# Windows 脚本与首次部署

这些 `.cmd` / `.bat` / `.ps1` 是仓库中已经提供的代码文件，下载后即可看到，不需要运行后自动生成。敏感配置、运行目录和 MCP 的实际机器路径在部署者主动初始化时生成。

本次整理没有执行下列任何入口。带“启动”“发送”“写日记”“连接手机”“安装”等字样的操作都可能实际运行程序、联网或改变本地状态，不能当成静态检查。

## 首次部署

1. 自行安装 Node 与 npm，解压或克隆到自己的目录。
2. 双击 `安装依赖.cmd`，或按根 README 的三条 npm 命令安装。脚本只安装本仓库声明的 npm 依赖，使用 `--ignore-scripts`；不会下载 QQ / NapCat / SnowLuma。
3. 双击 `Configure.cmd` / `配置百炼和QQ.cmd`。缺少的配置模板会先在本地创建，然后显示原有 GUI。填写自己的模型接口、模型名称、API Key、管理员和机器人 QQ。GUI 保存到被忽略的本地配置，不把真实值写入示例。
4. 自己编辑 `.env`，填写 `ONEBOT_ACCESS_TOKEN`、网关地址和需要的功能凭据。`.env` 中非空的主模型参数优先于 GUI；默认 `AI_BASE_URL/AI_MODEL` 留空，使用 GUI/JSON 值。
5. 独立安装并登录自己的 NapCat，配置 HTTP 与正向 WebSocket；或按 [GATEWAY.md](GATEWAY.md) 设置自己获得授权的本地启动器。
6. 确认白名单和角色卡，再双击 `Start.cmd` / `一键启动.cmd`。首次下载若缺配置，会先进入配置步骤；不会自动替你安装依赖或登录 QQ。

安装依赖、配置、启动是三个不同操作。下载/解压本身不会运行代码或生成私人数据库。

## 根目录入口

| 脚本 | 功能 |
| --- | --- |
| `初始化配置.cmd` | 仅创建缺少的本地模板、通用表情库和运行目录，并生成本机 MCP 配置；保留已有配置 |
| `Configure.cmd` / `配置百炼和QQ.cmd` | 原有图形配置界面；Key 输入使用密码框 |
| `Start.cmd` / `一键启动.cmd` | 启动当前目录的 companion 主链路 |
| `守护模式启动.cmd` | 使用恢复连接、进程监督与防自动睡眠的守护入口 |
| `Stop.cmd` / `停止全部.cmd` | 核验本目录进程标记、启动时间、Node 路径和完整命令行后，停止本副本机器人/守护/桥接及其子工具；不会按进程名结束其他 QQ 或机器人 |
| `Restart.cmd` / `重启机器人.cmd` | 停止本副本主链路并重新启动，不操作另一目录的机器人 |
| `Gateway.cmd` | 按自己的显式本地启动配置运行 NapCat；未配置时显示接入说明 |
| `检查环境.cmd` | 只读检查本地命令和必要文件是否存在，不请求网关或模型 |
| `查看日志.cmd` | 列出并查看本副本的本地日志；内容属于私人数据 |
| `写日记.cmd` | 使用自己的模型和当天授权交流生成本地日记；会请求模型，不向群聊或空间发布 |
| `看日记.cmd` | 查看本地最近日记；无日记时显示提示 |
| `自主行为设置.cmd` | 原有自主行为 GUI，配置时区、预演、暂停、空间行为与频率 |
| `主动私聊设置.cmd` | 原有主动私聊 GUI，配置开关、时段、唤醒与限流 |
| `暂停自主行为.cmd` / `恢复自主行为.cmd` | 修改全局暂停开关；恢复不会自动开启原本禁用的通道，也不会自动解除预演 |
| `配置空间.cmd` | 启用空间工具；自主发布仍需要另外明确开启；需要空间后端 |
| `连接手机.cmd` | 通过自己的 ADB 检测已授权设备、保存自己的序列号并启用手机工具 |
| `生成默认表情.cmd` | 用恢复的程序化绘图脚本在本地生成通用表情图片和目录，不需要公开个人素材 |
| `仅关屏保持机器人运行.cmd` | 关闭显示器并保持当前窗口防自动睡眠，不启动机器人。原入口中的私人昵称改为通用名称 |
| `配置DSH桥接.cmd` | 创建 DSH 路径的本地配置/角色卡并打开编辑器 |
| `DSH桥接启动.cmd` | 启动恢复的 DSH 桥接、社交模式和控制台；需要独立 DSH 服务，见 [DSH_BRIDGE.md](DSH_BRIDGE.md) |
| `安装依赖.cmd` | 部署者明确执行时，安装三个源码工作区的依赖，禁用安装脚本 |

主链路和 DSH 桥接是两条不同的运行路径。不要同时让它们处理同一网关的相同会话，以免重复回复。

## 保留的原子脚本和其他入口

- `local/configure.ps1`、`autonomy-config.ps1`、`chat-autonomy-config.ps1`：保留 GUI，改用自己的本地配置；必要时先初始化。
- `local/launch.ps1`、`restart.ps1`、`stop.ps1`：对应通用启停控制器。原 `DryRun` 参数不再被误当作离线检查。
- `local/phone-setup.ps1`：支持 `-Serial` 和自己提供的 `-KeyboardApk`；没有捆绑 APK，也不会默认安装来源不明的键盘。
- `local/build-stickers.ps1`、`keep-awake.ps1`、`screen-off.ps1`、`screen-off-native.cs`：保留通用绘图与电源相关入口/源文件。
- `ai-companion-kit/tools/安装.bat`、`启动.bat`、`写日记.bat`、`看日记.bat`：均转到本项目根入口，不依赖固定盘符。
- `ai-companion-kit/tools/install-node.ps1 -Version <自己确认的版本>`：自行执行时从官方地址取得指定 Node；没有捆绑安装包。
- `ai-companion-kit/packages/qzone/开通.bat`：启用本地空间工具配置，不直接发布内容。
- `qq-bridge/start.bat`、`restart.bat`：DSH 桥接的独立启动与重启入口。
- 原 `local/*.mjs` / `*.test.mjs` 和 `qq-bridge/scripts/*` 的可公开诊断、回归与工具代码已恢复。部分 `live-check` / `send-test` / `doctor` 会联网、发送或创建测试服务器，不应与 `检查环境.cmd` 混用。
- 原生 QQ/NapCat 迁移、会话观测、桌面接入等高级模块也保留在 `local/`。它们依赖用户自行取得授权的外部运行环境，见 [ADVANCED_INTEGRATION.md](ADVANCED_INTEGRATION.md)。

## 本地自动生成的文件

| 文件 / 目录 | 生成时机 |
| --- | --- |
| `.env`、主 `config.json`、本地 `role.md`、`local/features-settings.json` | 初始化/首次配置时，仅在不存在时复制模板 |
| `MCP配置.json`、`MCP空间配置.json` | 初始化/配置时，根据本机 Node 和本目录生成；含本机路径，默认忽略 |
| `data/stickers/library.json` | 首次初始化时用绘图脚本生成通用表情；也可手动生成或导入自己的资源 |
| 记忆、JSON/JSONL 状态、日记、附件与缓存 | 对应功能首次实际运行时按已有代码创建；不导入任何原账号数据 |
| QQ 自身数据库、Cookie 和网关登录状态 | 由用户自己的 QQ / 网关生成，不由开源仓库分发 |
| 测试媒体 | 使用保留的生成脚本或自己具有权限的样本准备，不能把原私人附件当测试集发布 |

MCP 示例的 `__PROJECT_ROOT__` 和 `__NODE_EXECUTABLE__` 是占位符，初始化会生成本机可用路径版本。不要把生成后的文件强制提交到 Git。

网关停止是独立授权项：只有本地启动配置显式 allowStop=true、由此副本登记、启动时间/可执行文件匹配且命令行包含本项目路径的隔离网关，停止全部入口才会结束它。独立安装的外部网关或身份无法核验的进程保留，由用户手动管理。

初始化保留已有 MCP 自定义配置。需要刷新本机 Node/项目路径时，单独执行 重新生成MCP配置.cmd；该入口会覆盖这两个本地 MCP 文件。
