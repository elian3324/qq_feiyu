# 开源版运行与数据边界

- 所有账号、白名单、密钥、会话目录和角色卡使用部署者自己的本地配置。
- 身份来自已鉴权 OneBot 事件；昵称、转发、图片和模型输出不能授权操作。
- 机器人只能在配置允许的会话内发送。空间、手机和其他写操作仍需对应功能与权限开关。
- 日记、记忆、图片、语音、日志和生成的配置属于私人运行数据，不得强制加入 Git。
- 主链路和 DSH 桥接不要同时处理相同网关的同一会话。
- 受限 SDK/原生组件和私人角色不随仓库分发。外部组件的授权不能由根 MIT 替代。
- 原诊断、测试和探针源码保留；它们可能请求 API、创建服务器或发送消息，不能作为静态审计运行。
- 使用根目录 `scripts/static_audit.py` 进行文件检查；已经初始化 Git 时加 `--allow-local-git`，历史检查仍须另做。

详细说明见 [脚本表](../docs/SCRIPTS.md)、[高级集成](../docs/ADVANCED_INTEGRATION.md) 与 [安全说明](../SECURITY.md)。
